# Storefront compliance checklist (20)

Engineering map for the legal / privacy / accessibility list. Templates are starting copy for Moroccan COD merchants (Law 09-08 / CNDP). They are **not** a substitute for counsel.

| # | Item | Status in Morea |
|---|---|---|
| 1 | Privacy policy | Per-tenant CMS `pages/privacy` generated by `Morea::PrivacyPolicy` + admin CNDP fields |
| 2 | Terms of service | Per-tenant CMS `pages/terms` via `Morea::TermsOfService` |
| 3 | Refund policy | Default `pages/returns` titled returns & refunds |
| 4 | Cookie policy | Per-tenant CMS `pages/cookies` via `Morea::CookiePolicy` |
| 5 | Cookie consent banner | Accept / reject measurement; Meta/TikTok load only when `morea_tracking_consent=granted` |
| 6 | Form consents | Checkout requires privacy/terms checkbox + CNDP rights notice |
| 7 | No useless data | Checkout + track copy collect only order fields; rights form minimization note |
| 8 | Audit third-party SDKs | See [third-party-sdks.md](third-party-sdks.md) |
| 9 | No dark patterns | Cookie reject is equal choice; promo codes opt-in; OAuth allow/cancel unchanged |
| 10 | No hidden fees | Checkout shows subtotal/shipping/total; footer pricing note; COD-only |
| 11 | No fake reviews | No review system shipped; merchants must not invent testimonials in CMS |
| 12 | No unsupported claims | Terms template forbids unverified regulated claims; merchants edit CMS carefully |
| 13 | Accessibility alt text | `product_image_tag` defaults alt to product name; keep decorative alts empty |
| 14 | Fix color contrast | Admin dark theme has contrast checks; storefront uses high-contrast ink/paper tokens |
| 15 | Keyboard navigation | Skip link, cookie dialog, cart drawer Escape + focus trap |
| 16 | Business details | Store legal name, registration, address in admin → footer imprint |
| 17 | Age consent | `minimum_purchase_age` + checkout confirmation + footer note |
| 18 | Unsubscribe | No marketing mailer; public rights form includes `unsubscribe` type |
| 19 | License fonts + images | See [asset-licenses.md](asset-licenses.md) |
| 20 | Data deletion request | Public `/:locale/privacy_rights` + admin queue; Shopify/Meta deletion flows remain |

## Surfaces

- **Tenant storefront:** legal pages, consent, imprint, rights form, a11y basics
- **Merchant admin:** legal settings, rights queue, pixel consent note
- **Platform / Seallo:** existing privacy & terms; apex footer imprint pointer
